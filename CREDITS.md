# Sound credits

All sounds in common/src/main/resources/assets/thewake/sounds/lib/ are real recordings or library assets taken from OpenGameArt.org and the Internet Archive. Each was cut, trimmed, converted to mono 44.1 kHz OGG Vorbis and loudness-normalized; the processing of each file is listed in docs/sound-manifest.json. Every source is CC-BY 3.0, CC0 or public domain, so the files can be redistributed in the mod jar, including commercially. The CC-BY 3.0 entries below must be credited (for example in the mod's README or credits screen) together with this note: "modified: excerpted, mono, normalized".
